## Start here

Read these files before making project decisions:

1. [Master Context File](documentation/Master%20Context%20File.md)
2. [HR Metrics and AYT Report Build Brief](documentation/HR%20Metrics%20and%20AYT%20Report%20Build%20Brief.md)

The build brief is the initial requirements source. The Master Context File
summarises report-wide scope, source behaviour and key decisions. Page Plans
owns the current page specifications, visual bindings, interactions and scoped
report validation. The backlog is the execution record.

## Project objective

Build and validate a two-page Power BI Desktop report that brings workforce and
Ask Your Team metrics together for the Leading Goals project. The report uses a
composite model built from the published `HR_Metrics` and `AYT_Metrics` semantic
models in the People & Capability workspace.

## Current status

The composite model and the Scores and Trend pages are built. Desktop
acceptance and published-viewer checks remain open as recorded in the backlog.
